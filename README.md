# Job Portal Backend

A RESTful backend application for a job portal, built with Node.js, Express.js, and MySQL.

## Overview

The Job Portal Backend is being developed as a modular server-side application for managing job listings, users, and job applications.

The project focuses on practical backend engineering principles including REST API design, relational database management, authentication, validation, error handling, and maintainable project architecture.

## Tech Stack

- Node.js
- Express.js
- MySQL
- JavaScript
- JWT Authentication
- bcrypt
- dotenv
- Postman
- Git & GitHub
